Use the template

  1. Download and open v4.1 in your browser.
  2. Export any existing data before importing a template.
  3. Click Import and choose the template JSON. Import replaces the current planner.
  4. Example dates automatically shift to start today. Rename the tabs and tasks to fit your lab.

Update log

v4.1 · Daily layouts, linked tasks & priorities
  • Choose Auto, Horizontal, or Vertical for each tab’s daily schedule. Auto uses vertical blocks for 8–10 days.
  • Vertical days have a large, bold date above the steps. Hide empty days when useful.
  • Add a task to another tab as a synchronized link or an independent copy.
  • Linked tasks keep their own position in each tab. Remove one appearance or explicitly delete the task everywhere.
  • Flag individual dated steps as priorities. Unfinished priority steps appear first in the daily schedule.
  • Import v3/v4 backups and export linked-task data in v4.1 format.
v4 · Flexible dates & task editing
  • Choose a 1–10-day range beginning on any date; open on today by default.
  • Store steps by calendar date and reorder task rows.
  • Fix start-only and end-only active date ranges.
  • Remove the step character limit and support line breaks.

Privacy & practical notes

The planner stores entries in this browser’s local storage. It does not send planner data to Su Lab or an external server and contains no analytics or tracking scripts.

Online tabs are views within your own planner, not multi-user collaboration. Data does not synchronize across devices or browsers.

Export JSON regularly. Browser data clearing, private browsing, a different browser, or moving a downloaded HTML file can make saved entries unavailable. The HTML download itself does not contain your saved entries.

The hosting provider may maintain ordinary website access logs. Those are separate from your planner entries.
